# Optimization_Methods

- The purpose of this repository is to work on the mathematics foundations of optimization, I use it as a deepening exercise after having a course on this topic.

- The First part is my work on the prerequisites needed to understand the course (notes, exercises, questions), the Second is the work itself on the chapters of this course pushed by a strong link with the maths seen before.

- The Third part is the folder used to make synthesis and links between topics and point out limits.

- The Fourth is needed to display the code made and used in order to understand some key concepts and visualize what happens when I break some hypothesis.

- Finally the Fifth part is made to build the final publication.
